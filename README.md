# VOXORA — Living Block Worlds (v1 foundation)

## Run
This is a browser-based Three.js project. Because it uses ES modules, run it through a local web server (not by opening index.html as a file).
- Install or use any static server, then serve this folder.
- Open the shown localhost address in Chrome/Edge.
- Internet is required for the Three.js CDN import.

## Controls
Desktop: WASD move, mouse look, Space jump, Shift sprint, left click break, right click place, 1–6 select blocks, E inventory, V camera.
Mobile: left joystick move, drag right side to look, Jump/Break/Place/Bag buttons.

## Current build
- Procedurally generated small voxel terrain, trees, water feature
- Three camera perspectives (including a custom close/front "Second" mode)
- Block breaking/placing, basic inventory, local save snapshot
- Day/night lighting cycle, shadows, quality presets
- Desktop and touch controls

## Important
This is a playable foundation, not the finished large game. Save currently stores a snapshot; full save restoration, chunk streaming, collision refinement, real Survival/Adventure rules, crafting, mobs, vehicles, electricity, weather, multiplayer, and APK packaging are planned development modules. Quality presets are limited by the device GPU.
